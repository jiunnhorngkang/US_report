# US_report — 軟組織超音波報告系統

單一 HTML 檔的網頁工具，免安裝、免伺服器。直接用瀏覽器開啟 `index.html` 即可使用
（或於 repo Settings → Pages 啟用 GitHub Pages）。

## 功能
- **當日病患流水號**：只輸入流水號，不需任何其他個人辨識資料。
- **部位勾選**：肩、肘、膝、踝，各可選左／右。
- **常見超音波發現勾選**：依結構分類（肌腱、韌帶、滑囊、關節、神經等），
  部分項目（撕裂、鈣化、積液、厚度等）可填數值。每部位另有「其他發現」自由輸入。
- **自動產生報告**：檢查所見（未勾選的結構自動列為未見明顯異常）＋ 診斷印象 ＋ 建議／備註。
  報告語言可切換 中文／English。
- **輸出當日所有報告**：依流水號排序，可一鍵複製、下載 .txt 或列印。
- **匯出／匯入備份**：以 JSON 備份當日資料。

## 資料儲存
所有資料僅存於本機瀏覽器 localStorage，不會上傳到任何伺服器。
更換電腦或清除瀏覽器資料前，請先「匯出備份」。

## 修改勾選項目
編輯 `index.html` 內的 `PARTS` 陣列即可新增或調整結構與發現：
`T(id, 中文, English, 單位)`。
